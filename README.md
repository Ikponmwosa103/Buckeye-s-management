# Buckeye State Welding & Fabricating — Upgraded Website

Premium industrial single-page website redesign for Buckeye State Welding & Fabricating (Elyria, Ohio).

## What’s new (v2.0 upgrade)

- **Deeper industrial design system** — refined navy/charcoal palette with electric cyan accents, improved typography scale, and stronger visual hierarchy
- **New Process section** — clear 4-step journey from inquiry to delivery
- **Tabbed Equipment panel** — switch between Machining, Cutting and Fabrication capabilities with matching imagery
- **FAQ accordion** — common questions answered for faster decision-making
- **Enhanced testimonial** — featured customer letter with improved presentation
- **Benefits grid** — capacity, responsiveness, daily delivery and generational craftsmanship
- **Improved motion** — progressive reveal, scroll progress bar, hover lifts, equipment image cross-fade
- **Better accessibility** — ARIA roles on tabs & menus, focus states, reduced-motion support
- **Fully expanded, maintainable CSS & JS** — no minified source, clear structure
- **Mobile-first refinements** — improved hamburger nav, responsive grids, touch-friendly targets

## Run locally

```bash
npm install
npm run dev
```

Or with pnpm / yarn:

```bash
pnpm install && pnpm dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project notes

- Built with semantic HTML, modern CSS and vanilla JavaScript, served by Vite.
- No backend or CRM is included.
- The quote form performs browser-side validation and displays a demonstration state only. It does not transmit information or attachments.
- Industrial photographs are illustrative remote images. The portfolio explicitly labels imagery as illustrative, not as completed Buckeye customer projects.
- Company history, published services, equipment details, facility addresses, phone numbers and the customer quotation were summarized from the official Buckeye State Welding & Fabricating website.
- No public email address was available in the official pages reviewed, so none is invented.
- Confirm all company details and current equipment availability with Buckeye before using this concept as a live production website.
